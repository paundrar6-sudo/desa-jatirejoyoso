Folder ini digunakan untuk menyimpan file video profil atau short movie Desa Jatirejoyoso.

Contoh file yang dapat diletakkan di sini:
- profil-desa.mp4
- short-movie-jatirejoyoso.mp4

Format video yang direkomendasikan:
- Ekstensi: .mp4 (H.264 / AAC)
- Resolusi: 1080p (Full HD) atau 720p (HD)

Website profil desa telah dilengkapi video player HTML5 yang secara otomatis memutar video lokal dari folder ini, serta mendukung opsi embed video YouTube.
